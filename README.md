# LexIntel-AI

**AI-Powered Legal Intelligence System**

LexIntel-AI is a legal intelligence application designed to help users explore legal documents and ask questions using AI-powered retrieval and response generation.

## Features

- AI-powered legal question answering
- Legal document upload and management
- Retrieval-Augmented Generation (RAG)
- Document citations and source references
- User authentication
- Evaluation metrics and testing

## Tech Stack

### Frontend
- React
- Vite
- JavaScript
- CSS

### Backend
- Python
- FastAPI
- SQLAlchemy
- AI-powered retrieval and generation

## Getting Started

1. Clone this repository.
2. Follow the setup instructions in `backend/README.md` or the backend configuration files.
3. Follow the frontend setup instructions in `frontend/README.md`.
4. Configure the required environment variables using the provided `.env.example` files.

## Environment Variables

Configure your own environment variables using the example files. Never commit API keys, passwords, or other secrets.
